# ex8-tot

Terraform, GitHub Actions, EKS, Argo CD를 이용한 최종 CI/CD 및 GitOps 프로젝트

## Structure

- infra/public-state : Terraform Remote State
- infra/resource : AWS / EKS Infrastructure
- k8s : Kubernetes / Argo CD manifests
- app/company : Company frontend/backend
- app/board : Board frontend/backend
